PocketBeat M3 — original offline-authored meter-scale glTF 2.0 asset. 2898 triangles, 10 PBR material batches, UVs and normals. Graphite ABS, copper band, silicone pads, machined knobs, LEDs, rear ports, feet, engraved faceplate glyphs. Editable source: tools/instruments/author_pocketbeat.mjs (Node.js, no packages). ## Ironwake Instrument Works — Brickwater, Morrow Bay

- Breaker G6: original six-string electric guitar, approx. 0.94 m overall, 648 mm scale, 24 frets, deep petrol lacquer, 4,244 triangles.
- Dredge B4: original four-string electric bass, approx. 1.16 m overall, 864 mm scale, 22 frets, oxblood lacquer, 3,700 triangles.

Both models feature distinct asymmetric beveled bodies, actual string geometry, nickel frets, bridge saddles, pickups, tuning machines, control knobs, rear plates and strap buttons. Nine material batches each; no downloaded IP, explicit normals, UVs and material factors. Source: `node tools/instruments/author_ironwake.mjs` from repo root. Both are static display props; they are **not purchasable or playable yet**. UVs are provisional planar coordinates rather than a finished texture atlas; no baked normal/roughness textures. Native geometry, scale, clipping, material and frame pacing review outstanding. All dimensions are authored design targets, not measured in-engine results.

## Reconciled musician art library
Six older offline-authored OBJ meshes (acoustic guitar, bass, portable synth, combo amplifier, mic stand, road case), four SVG texture assets, shared wear shader and four PCM demo WAVs were preserved byte-for-byte from PR #315. `scripts/instrument_art.gd` provides a reusable static mesh/material factory. The rhythm smoke now verifies each imported mesh and audio demo. These are supplementary art resources, not a replacement for PocketBeat or Ironwake, and are not yet connected to purchase, NPC performance or band progression. The original OBJ/WAV assets lack an editable authoring source in this port; native visual/scale/audio acceptance is pending. See `assets/music/provenance.json` for original Git blob identities.
