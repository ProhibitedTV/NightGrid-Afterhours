# SYNAXIS OMNISYSTEMS | Corporate identity 2036

Original fictional brand for NightGrid: Afterhours. Designed to look like a vertically integrated technology corporation, not a parody of any actual logo.

- Emblem: a hexagonal enclosure and an angular S-shaped data path.
- Wordmark: custom seven-letter outlined vector geometry; no external font dependency.
- Light lockup: warm white and signal aqua on midnight navy or glass.
- Dark lockup: midnight ink and teal on warm paper.
- Preserve 4:1 lockup aspect ratio. Leave at least one eighth emblem width as clear space. Use standalone mark only when the wordmark is too small.
- Palette: navy #152E40, ink #12232F, aqua #95E3D6, white #F3F5F0, paper #E8E8DF, investor gold #F1C879, action red #AD4040.

SVG sources are original repo assets. Godot imports them as textures. No duplicated baked artwork, font files, external brand imagery or network dependency.
