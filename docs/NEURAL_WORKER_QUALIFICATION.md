# Neural worker qualification (#595)

Research-only registry: no model installation, downloads, inference, auto activation or changes to #591. Run `python3 tools/asset_refinement/neural_worker_gate.py` for the shortlist. Once an operator has reviewed exact licensing and run an isolated local pilot, use `--worker ID --evidence /path/to/private/qualification-folder`. The folder must include qualification.json, the exact weights, environment/dependency records, license evidence and three or more paired test cases. See test_neural_worker_gate.py for the field schema (fixture values are NOT approval). The script hashes evidence and validates explicit human decisions. A passing report means eligible for adapter review, NEVER automatic production enablement.

Qualification sequence: check exact code and checkpoint revisions plus all auxiliary models/voices and commercial eligibility; explicitly approve setup separate from unattended production; compare at least three representative owned inputs against existing worker on RTX3060 12GB, with technical and human acceptance for each, offline run and measured peak RAM/VRAM/time. Proposed 10240 MiB peak VRAM ceiling is a pilot safety margin, not measured performance or assurance; local guard and SSD/NAS reserve remain necessary. Test native imports/rigs/materials where applicable, license and source rights independently. Keep evidence private; no weights in Git.

A qualified worker still needs a separate adapter PR: fixed executable and arguments, immutable inputs/output hashes, isolated env, existing factory GPU lease and guard, deterministic resume, candidate-only output manifest, failure recovery, no implicit downloads, no dynamic executable from evidence JSON. Review exact qualification digest and adapter tests; explicitly select the new worker in a versioned job catalog. Current baseline remains active until that gate passes. Never automatically substitute a model after a failure or silently carry approval over a new checkpoint. No Codex required for routine dispatch. Codex remains for native game testing. Published license hints are not legal approvals.
