## Offline analysis

Run `python tools/analyze_vehicle_trace.py path/to/capture.csv` with the paired sidecar beside it. Add `--baseline path/to/earlier.csv` for signed after-minus-before latency deltas. The report includes all/foot/driving and streaming-active/idle percentiles, transition groups by model/action/result, synchronous stage timings, complete 12-frame window peaks and worst event indices. Missing sidecars still permit overall frame analysis; malformed or mismatched sidecars fail rather than silently misattribute measurements. Partial windows are counted but excluded from peak comparisons. Use like-for-like hardware, graphics settings and scenarios; keep cold and warm runs separate. Negative latency deltas mean shorter measured intervals, not proof of a particular cause.

Run analyzer unit tests: `python -m unittest discover -s tools -p test_analyze_vehicle_trace.py`.
