# Original task chair — #442
The committed glTF contains 5947 vertices, 9792 triangles, UVs and four material surfaces. It replaces the legacy runtime cube/cylinder chair assemblies in the ground office and shared workfloor kit (including inherited chairs in B1 and executive spaces). Modelled offline with a reproducible geometry authoring script: rounded cushion shells, contoured back, lumbar support, tapered spokes, paired casters, height column, armrests and adjustment lever. Materials are original PBR factors, not photo texture maps. Each floor uses one shared MultiMesh with the existing chair anchors and no new collision, scene update or per-frame synthesis. No claim of visual realism until native inspection; verify seat alignment with staff, close camera framing, mesh silhouettes and performance. Future work: distinct executive chair, texture maps, desks and monitors.
