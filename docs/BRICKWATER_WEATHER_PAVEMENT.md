# Jade Wash / Brickwater visual target — wet alley pass

Reference direction: a red sculpted sports car under cyan laundry signage and warm/magenta practical lights; textured damp brick, dark pavement, broken puddle reflections and grounded utility clutter. The supplied concept is an artistic target, not a game screenshot.

This pass synchronizes the existing photographic concrete shader with the same slowly accumulating and drying weather film as Cinder paint. Existing drainage masks keep puddles localized; rain darkens aggregate and expands reflections. Fine ground-space ripple normals are attenuated by pixel footprint. No new nodes, lights, collision, reflection cameras, or screen copies.

Acceptance: park the Cinder by Jade Wash, freeze time with Y, cycle clear/rain/storm/clear via F2 and wait for the film to accumulate or dry. Capture F10 from identical low three-quarter angles. Look for stronger localized sign reflections in rain, rough exposed concrete islands, no distant shimmering and unchanged floor contact. Use F8 cold/warm runs to evaluate cost. The numeric test mirrors the wetness transfer curve; it is not a visual acceptance or frame-rate result.

Remaining reference gaps: actual body silhouette and surfacing, windscreen transmission, masonry depth, warm local vent lighting and steam, long-range storefront composition. Require native Forward+ review before claiming fidelity.
