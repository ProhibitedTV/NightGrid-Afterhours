# Clock atmosphere update deduplication

The original day/night controller reapplies atmosphere and lighting every 200 ms, even at an unchanged paused hour. This change skips redundant environment/sun writes at an identical hour/profile and skips sky-color rewrites when daylight amount is unchanged. Manual hour/profile changes and reconfiguration still apply immediately. City material, practical light and landmark subscriptions retain their original notification cadence so new streamed geometry can synchronize. No requested changes to fog, colors, exposure, tone mapping, shadows or gameplay. The smoke test exercises real Godot resources and notification cadence; only a native frame-time A/B can establish a measured improvement. Post-beta.7 candidate, independent of active capture.
