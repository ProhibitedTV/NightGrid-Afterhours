# NightGrid: Afterhours — Beta.8 RC9 | Morrow Bay Comes Alive

Windows x64 public playtest prerelease, Godot 4.7.2 / Forward+ / Vulkan. Published only from exact current main after successful project preflight, Windows export, delivered Windows startup smoke, and offline audio verification. No model downloads, WSL, or inference are needed to play.

- Eight additional voiced lines: 86 of 88 authored dialogue cues, including all 27 corporate cues and 59 of 61 street/venue cues. Existing recordings remain unchanged.

## Run the playtest
Extract the entire Windows ZIP to a fresh folder; keep NightGrid-Afterhours.exe and NightGrid-Afterhours.pck together. Back up existing saves and start a New World. Read BUILD-INFO.txt for the exact source and PLAYTEST-GUIDE.md for routes and reporting. The previous RC8 remains a rollback.

## Focused acceptance
1. Play the Synaxis opening through offboarding: conference, Mandarin call/captions, breakroom choices, elevator, printer, server room and coffee. Check that advancing stops old speech.
2. Walk stone, tile, asphalt and gravel; compare cadence, volume and variation. Listen to industrial, waterfront and road ambience; test traffic, braking, bus/rail doors, pickups and deliveries.
3. Listen to street conversations and NightGrid FM in vehicles and venues. Check competing audio, transitions, looping seams and dialogue volume.
4. Enter INSERT COIN, set a record, leave and return, then save/reload; physical displays should match saved progress.
5. Drive across sectors and capture native frame pacing and any collision/visual regressions. F7 marks incidents; F8 captures frame traces; F10 saves screenshots where supported.

## Known limitations
This is provisional playtest audio, not human listening approval or final release certification. Two flagged voice lines retain text fallback: street.robot_romantic.quest.complete and street.rae.soundcheck.ending. Automated checks do not establish perceptual quality, native gameplay performance, controller comfort or full-route save compatibility. Report issues in context rather than auditioning every individual file.
