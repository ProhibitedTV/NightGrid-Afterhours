# MBPD communications and station refinement
MBPD uses familiar public radio vocabulary adapted for the fictional city: 10-4 (acknowledgment), 10-8 (in service), Code 4 (no additional assistance needed), and brief plain-English incident dialogue. Reference: [City of Tucson public Radio Signal Codes](https://www.tucsonaz.gov/Departments/Police/Radio-Codes). Definitions vary by agency; this is a game-specific selection of routine terms. Dispatch and unit acknowledgments derive from live event sequences, not fabricated reports or real transmissions. Single non-overlapping receiver on WorldSFX, maximum six queued messages, repeat deduplication, matching caption generated from the same dialogue source as speech, and short closure tail. The player hears the channel while wanted or visiting a precinct; no network requests, microphones or real radio access. Local builds without optional generated speech assets fall back to a UI chirp and caption. CI and Windows beta/export generate eight actual spoken WAV clips using offline eSpeak NG and original radio filtering; no redistribution of recorded voices. For a local full-voice build install espeak-ng and run python3 tools/generate_mbpd_radio.py before Godot import. Original frontage canopy, metal/concrete/PBR details, duty staff with existing idle animation, and live dispatch board in both station rooms. Existing addresses, collisions, room streaming and fleet budget retained. Native audio intelligibility and art review pending. Future: professional voice pack, authored glTF architecture, garage/depot models.
