# Vending, food and stamina — initial gameplay pass

Physical machines replace the original decorative Afterhours vending props. G/X at the front opens a three-option shop with two deterministic product assortments across the existing machine locations. Purchases go to a 12-item pack. R/D-pad down chooses the owned item that best addresses current health and stamina deficits; if none is useful, the original ration action is retained. Five fictional brands, original price/effect data; no mandatory hunger/thirst. Sprint drain 14/s, jump 12, recovery 18/s after 0.8s, exhaustion hysteresis at 20. Café drinks restore 40 stamina, stalls 20; existing price/health/heat remain. Optional save fields accept old v1 saves; inventory IDs and quantities are bounded on restore. Machine bodies stream with the parcel. First-pass box-model art and menu UI, no dispensing animation or dedicated sound yet. No melee implementation in this pass. Expand to other districts and interiors after validating placement and RC6 integration. Test verifies physical machine menu, purchase, consumption, stamina and old save defaults; native UI/performance pending.
