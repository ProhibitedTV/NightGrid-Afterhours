## Offline foliage rendering (issue #586)

The single-shot run now renders seven botanical pilot LOD0 meshes at eight azimuths and two elevations, twice: unlit base color and encoded camera-space normals. The default is 512 px per view, 32 CPU Cycles samples, two threads, 224 total renders; one 2048x2048 RGBA atlas per species per channel (14 atlases). Private per-view PNGs and camera metadata remain on Z: under `Visual/Impostors/render-001`. Complete species are verified by source/settings/output hashes and skipped on retry. The existing resource guard supervises the CPU process. This uses the current botanical geometry as source, not a new high-poly photoreal master. No shader or asset is added to the live game yet. Review alpha edges, mip bleeding, normals, view transitions, wind/shadow behavior and native GPU overdraw before promotion. The two atlases together are about 10.7 MiB per species with full BC7 mip chains, hypothetical only; compression, sharing and residency require actual import testing.

The building lane emits TEXCOORD_1 with global non-overlapping, world-size-proportional rectangular charts and four reference-pixel gutters at 2048²; density and occupancy are recorded. Actual Godot import, atlas allocation, shared seams and native bake quality remain acceptance gates. `--check` runs preflight only (existing Node 24, both Godot executables, Blender, mesh dependencies, NAS and safety telemetry). Override Linux Godot with `--linux-godot`. No visual setup auto-install if the existing setup marker is missing. Review packet and inventory hashes are captured at completion and rechecked before indexing.

Architecture now includes a texture-free, under-256 KiB LOD2 visual proxy per family and four-triangle conservative occlusion candidate (two inset opaque side-wall planes). LOD2 preserves the major silhouette, not the close-up façade. No collision, gameplay placement, live occluder, or window culling is changed. The evidence index requires all four derivatives. Runtime validation must bind exact geometry and compare silhouette/visibility and frame times; whole-block HLOD is still pending.

The offline environment lane adds ten original 1024x512 linear RGBE sky candidates (eight daytime/night presets aligned by name with the current sky library, plus overcast-night and storm-night), each with a fixed-exposure review JPEG, radiance statistics and hashes. These are analytic procedural skies, not scanned HDRIs or precomputed local reflection probes. No sharp sun disc is baked; live directional light remains separate. No changes to the game's existing scenic LDR artwork. Native HDR import, radiance orientation, energy and performance A/B remain mandatory.

The street-weathering lane produces eight original 512² decal tiles packed into two 2048×1024 RGBA atlases (sRGB albedo/coverage and linear ORM/coverage), plus a review JPEG and nominal metre-scale/receiver metadata. Covers asphalt cracks, tire marks, oil, puddle edges, salt, rust, spalls and indoor boot scuffs. This is a procedural pilot, not a photo scan; no normal or emissive maps, automatic placement or wet reflection integration. Native atlas slicing, mip safety, receiver masks and overdraw acceptance still required.
