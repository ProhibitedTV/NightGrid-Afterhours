# Original Morrow Bay harbor crane mesh
Seven existing permanent crane anchors now reference a shared original
offline-authored glTF lattice tower crane. Crossbracing, tower legs,
a trussed 35 m jib, machinery counterweight, operator cab, ladder, trolley,
hoist cables and hook replace the four old primitive blocks. Source meter
scale; fixed placement above existing pier decks. West Docks instances
rotate along the pier orientation. Three material groups; two reuse existing
photographic steel maps from the documented Crane & Gear art pipeline
(see docs/CRANE_GEAR_ORIGINAL_GLTF_ART.md); no new external asset license.
The original design geometry is reproducible from the included JS recipe.
This is a distant skyline asset with opaque cab glazing, not a usable crane
or an AAA final asset. No new collisions, lights, moving parts or gameplay.
Seven instances share the imported mesh, shadows disabled for distant props.
Native same-camera screenshots, dusk/day inspection, material scale, silhouette
and RTX 3060 GPU measurements are still required. Do not label as final art.
