# Photographic asphalt face orientation

The nine-image beta.7 candidate's actual Vesper vehicle captures reveal large square patterns in the road. Source review found that the new photographic street surface used counterclockwise triangle order as viewed from above while Godot defines clockwise front faces. With back-face culling enabled, this can expose the underlying tiled foundation instead of the photographic asphalt. This correction reverses each triangle's order, preserving the upward normal, world-aligned UV scale, tangent handedness, 837 nonoverlapping rectangles, material properties, and all collision geometry. Regression checks now inspect winding and tangent basis of every actual mesh triangle. This is a post-beta candidate; rerender the actual street gallery and confirm the difference in native Windows before claiming visual resolution. Do not substitute concept images or claim that the current gallery contains the correction.
