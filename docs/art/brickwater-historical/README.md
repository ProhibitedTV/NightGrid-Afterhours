# Brickwater historical development record

The original phase notes and unused original art below are preserved byte-for-byte from PRs [#156](https://github.com/ProhibitedTV/NightGrid-Afterhours/pull/156) and [#157](https://github.com/ProhibitedTV/NightGrid-Afterhours/pull/157). These are historical documents, not instructions to check out old branches or replace the current game. Relative links and commands in the originals describe their original checkout.

**Current implementation:** [Brickwater consolidated](../../BRICKWATER_CONSOLIDATED.md), [native matched review](../brickwater-consolidated/README.md), [seven archived software-rendered frames](../../screenshots/brickwater-review-archive/GALLERY.md).

All 73 files from the nine pinned Poly Haven source packages match both historical branches exactly on current main. The consolidated integration already describes the explicit decisions: use #157's apartment/service layer and #156's architectural envelope ideas, omit its duplicate fixtures and alternate sign set. Newer streaming, workroom, lighting, and storefront code is not replaced. The historical capture/publish workflows are superseded by the consolidated capture harness; no obsolete auto-publishing workflows are reintroduced.
