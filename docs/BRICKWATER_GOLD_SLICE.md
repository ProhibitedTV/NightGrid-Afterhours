# Brickwater gold vertical slice — first integration of acquired high-fidelity art

Target: the approved narrow, lived-in cyberpunk service alley; not a completed AAA scene. The first visual benchmark is the stable existing block (-2,1), centered at (-87,0,87). This branch combines the already pinned source packages (#153) with physical alley and original wall art (#143/#154). All upstream glTF, textures and SOURCE manifests are preserved without copy/re-download.

Real selected **source** mesh members, not kit showroom scenes: six window assemblies (large west/double east, upper street level), two industrial caged wall lights, two joined 2 m metal riser modules plus three support fittings, five electrical cable sections and six grouped waste/delivery props including hand truck, crates, carton and bags. Shared mesh cache; original materials, UVs and source asset names. Ground props sit on existing physical floor and have size-matched proxies. Two local shadowed warm lights only. Building shell and original wall paint remain, no fake traversable interior; existing upper facade silhouettes are not solved. No random placements, new save data or runtime downloads.

## Repeatable real-game visual acceptance
Added tools/capture_brickwater_gold.gd. Run **in an imported desktop project**, using the existing Windows Godot 4.7.2 executable (not --headless). Set NIGHTGRID_GOLD_CAPTURE_DIR to an absolute nonexistent folder, NIGHTGRID_SOURCE_REVISION to the checked-out commit SHA, and execute: `godot --path . --rendering-method forward_plus --rendering-driver vulkan --resolution 1920x1080 --script res://tools/capture_brickwater_gold.gd`. Four raw framebuffer PNGs and camera/clock/renderer metadata are saved. Copy the identical script to a baseline checkout for exact comparison (no resource dependency on the new alley art), preserve the original captures separately; do not overwrite or fake them. The staged view is not a gameplay benchmark: additionally record F8 during ordinary walking/driving. This tool has not yet produced native verified frames.

## Real architectural envelope pass
Both pilot parcels now replace their rendered BoxMesh shell with five continuous outer surfaces and four detailed storeys (bounded by actual saved height) of paired source `wall_window_centered_*_03` aperture meshes and `window_centered_*_03` assemblies. Each uses the same source origin; the glazing is geometrically recessed, with a sealed dark backing 36 cm behind the wall plane. Ground-level masonry stays at the original boundary so existing graffiti and services remain attached. Residual bays and top bands are closed, no open edges or claims of enterable apartments.
